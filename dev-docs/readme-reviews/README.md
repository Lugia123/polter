# README 陌生读者评审记录

每一轮的输入、原始反馈、据此做的改动，以及**没有采纳的部分和理由**。一轮一个
文件，按日期命名。

## 这是什么，以及它不是什么

**读者是 LLM 扮演的，不是真人。** 每一轮都用全新的 agent，给一个具体的开发者身
份，只给它一份去掉出处的 README，禁止它读代码、搜仓库或使用任何关于本项目的先验
知识。中英两份**由不同的 agent 分别读**——同一个读者读完一份就已经理解了产品，
第二份的第一印象就没有了，而第一印象正是要测的东西。

这个方法能可靠地发现的：术语在定义之前就使用、信息顺序不对、承诺与限制不对称、
以及**一句话被理解成了完全不同的意思**。第一轮两个独立读者对同一句话产生了同一个
错误理解，这种一致性是有信息量的。

它**不能**替代真人用户。它不会因为烦躁而关掉页面，不会有真实的机会成本，也不会
在三天后回来告诉你哪一步实际卡住了。真人的一句"我看不懂"仍然比这里的一整页有分
量——第一轮就是由一位真人读者的反馈触发的。
