# 截图：全局快捷键、框选与标注、粘进 AI CLI

> 状态：设计已定（2026-10-06），开发中。本文是 mac 与 Windows **共用的一份规格**，
> 两边实现都以这里为准；两边有出入时，先改这份文档，再改代码。GTK 本轮不做。

## 1. 要做成什么

开着 Polter 就能截图，体验参考微信截图：按全局快捷键 → 屏幕定格 → 鼠标悬停时自动框住
光标下的窗口，点一下选窗口，拖动则自由框选 → 在选区上标注（框、箭头、画笔、写字、编号）
→ 完成。结果可以粘进 Polter 里正在跑的 AI CLI，也可以粘进别的应用（微信等）。

与微信截图的一处关键不同：**标注是可读的数据，不只是画在图上的像素。** 用户写的字、
框住的位置，以文本形式随图片一起交给 AI，不需要它再从图里认字。

分两步交付，第 1 步不依赖第 2 步。

## 2. 第 1 步：图片粘贴（零权限）

现状：剪贴板里只有图片时两边都粘不进来（核心的普通粘贴只向宿主要 `text/plain`；
mac `getOpinionatedStringContents` 返回 nil，Windows `read_clipboard_text` 只认
`CF_UNICODETEXT`）。

改成：宿主在回答普通粘贴的 `text/plain` 请求时，若剪贴板**没有文本、没有文件、但有图片**，
就把图片存成 PNG（§5），把**路径**当作粘贴文本交回核心。之后与拖一个文件进终端同路：
走 `completeClipboardPaste`，终端开了 2004 就带 bracketed 帧。

- 全在宿主里做，核心的粘贴路径不改。
- 优先级：文本 > 文件 URL > 图片。剪贴板同时有文本和图片（从网页复制）时仍粘文本。
- 路径转义沿用各自拖放的现成规则（mac `Ghostty.Shell.escape`，Windows `polter_droppath`）。
  整段粘贴只含这一条路径，不加尾随空格或换行——Codex 要求整段恰好是一条路径。
- 同一张图连粘两次不重复存盘：记下剪贴板的变更序号（mac `changeCount`，Windows
  `GetClipboardSequenceNumber`）与上次存出的路径，序号没变就复用。
- 开关：配置项 `clipboard-paste-image`，默认 `true`。关掉后行为与今天逐字节相同
  （Windows 上 `ctrl+v` 继续穿透给 pty，由 CLI 自己读剪贴板）。
- Windows 顺带补上：剪贴板是 `CF_HDROP`（资源管理器里复制的文件）时粘出路径，mac 已有。

## 3. 第 2 步：截图

### 3.1 触发

两套触发，互不依赖，各自可改可关。

**纯键盘。** 新键位动作 `screenshot`（无参数）。默认绑定是**全局**的：
mac `global:cmd+shift+0`，Windows `global:ctrl+shift+0`。用户在配置里用普通的
`keybind = …=screenshot` 改；设置窗口的快捷键页目前只读，本轮不改它。
⚠️ Windows 上 `ctrl+shift+0` 历史上会被「切换输入语言」的系统热键吃掉（装了多个输入法
时），是否注册得上、按了有没有反应是真机验收的一格；不通就换默认值，不许留一个按不出来
的默认键。

**键盘 + 鼠标。** 按住修饰键双击左键：mac `cmd+shift`，Windows `ctrl+shift`。一只手
在键盘、一只手在鼠标，都不用挪。配置项 `screenshot-mouse-trigger`，值是修饰键组合
（如 `cmd+shift`）或 `none`（关掉），默认开。

- 双击的位置有用：覆盖窗口出来时，**光标下的那个窗口已经是选中状态**，直接标注或按
  `Enter`；不合意再拖动重选。
- 「双击」按系统的双击间隔和距离判定（mac `NSEvent.doubleClickInterval`，Windows
  `GetDoubleClickTime` / `SM_CXDOUBLECLK`），两次按下时修饰键都要按着，且**只有**这几个
  修饰键（多按一个不算）。
- mac：用全局鼠标事件监听，**不许因此要辅助功能或输入监控权限**（预期鼠标事件的全局监听
  不需要授权——没实测，开工先量；若量出来要授权，mac 这一套改为默认关并在群里报）。
  监听吃不掉事件，所以两次点击都会照常落到下面的应用上。
- Windows：低级鼠标钩子放在**独立线程**上（钩子过程慢了会拖住全系统的鼠标，主线程不许
  挂它），第二次按下吃掉、第一次放行。
- 已知代价：第一次点击（Windows）或两次点击（mac）会被下面的应用收到——点在链接上会
  开新标签页，点在标题栏上可能缩放窗口。文档里写明「点在空白处」。
- ⚠️ mac 现有的 `global:` 键位走事件监听，要「辅助功能」权限。**默认的截图快捷键不许
  因此在启动时弹辅助功能授权**——用不需要该权限的系统热键注册实现（Carbon
  `RegisterEventHotKey`）。Windows 已有 `RegisterHotKey`（`quick.rs`）。
- 热键被别的程序占了、注册失败时要出声（日志 + 一次性提示），不许沉默。
- 菜单和命令面板各有一项「截图」，显示当前绑定的键。

### 3.2 选区界面

- 触发瞬间把所有显示器截下来定格，每个显示器一个全屏覆盖窗口显示定格画面。
  之后的选择、标注都在定格画面上做（菜单、悬停态不会跑掉）。
- **窗口自适应**：鼠标移动时高亮光标下最上层窗口的边界（不含 Polter 自己的覆盖窗口）。
  单击 = 选这个窗口；按下拖动超过 4 px = 自由框选。本轮只到窗口一级，不识别窗口内控件。
- 选区定下后：八个手柄可调大小、可整体拖动；旁边显示尺寸（像素）。
- `Esc` 取消（无任何副作用：不动剪贴板、不留文件）；右键 = 退一步（有选区则清选区，
  没有则取消）。
- 多显示器、各显示器缩放不同的情况都要对：存出的图是**物理像素**，选区不跨显示器
  （跨了就夹到起点所在的那个）。

### 3.3 标注工具

选区下方一条工具栏（放不下就放上方或选区内）：

| 工具 | 说明 |
|---|---|
| 矩形 | 空心框 |
| 箭头 | 起点到终点 |
| 画笔 | 自由线 |
| 文字 | 点一下出输入框，支持中文输入法 |
| 编号 | 点一下放一个圆形序号 ①②③…，可紧跟着输入一句说明 |
| 颜色 | 至少红、黄、蓝、白四色，默认红 |
| 撤销 | 逐步撤销，`cmd/ctrl+z` |
| 取消 | 同 `Esc` |
| 完成 | 同 `Enter` / 双击选区 |

本轮不做：马赛克、椭圆、钉在屏幕上、长截图、录屏。

### 3.4 完成后去哪

完成时固定做两件事：

1. 把**合成图**（截图 + 全部标注画上去）写进系统剪贴板 → 可粘进任何应用。
2. 把合成图存成文件，并写旁路文件（§4）。

然后：**若触发热键那一刻 Polter 是前台应用**，直接把结果送进当时聚焦的窗格
（等同第 1 步的粘贴，见 §4.2）。否则不送——用户回到 Polter 按粘贴键时，第 1 步的
图片粘贴认出「剪贴板里这张就是刚才那张」（按变更序号），复用已存的文件并带上标注文本。

## 4. 可读的标注

### 4.1 旁路文件

每张截图 `<name>.png` 旁边写 `<name>.json`（UTF-8）：

```json
{
  "version": 1,
  "image": "20261006-153012-123.png",
  "taken_at": "2026-10-06T15:30:12+08:00",
  "size": [1280, 800],
  "scale": 2.0,
  "source": {"kind": "window", "app": "Google Chrome", "title": "…"},
  "annotations": [
    {"n": 1, "type": "number", "at": [412, 96], "text": "这个按钮没对齐"},
    {"type": "rect", "rect": [380, 80, 240, 44], "text": ""},
    {"type": "arrow", "from": [100, 300], "to": [220, 340]},
    {"type": "text", "at": [60, 500], "text": "间距太大"},
    {"type": "pen", "bbox": [10, 10, 80, 40]}
  ]
}
```

- 坐标全部是**图片像素**，原点左上，`rect`/`bbox` 是 `[x, y, w, h]`。
- `source.kind` 是 `window`（单击选的窗口）或 `region`（自由框选）；`app`/`title`
  只在 `window` 时写，取不到就省略该键，不写空串。
- 其余元信息（URL、git、归属、文字识别等）本轮不做，`version` 留着给以后加字段。

### 4.2 送进终端的文本

送进 Polter 窗格时**分两次粘贴**：

1. 第一次：只有图片路径（规则同 §2）。AI CLI 把它识别成图片附件。
2. 第二次：仅当有带文字的标注时发，一段单行文本，例如：

   `[截图标注 1280×800] ① (412,96) 这个按钮没对齐；文字 (60,500) 间距太大；框 (380,80,240,44)；箭头 (100,300)→(220,340)。详见 <json 路径>`

   没有任何标注时不发第二次。只有图形、没有文字时也发（位置本身就是信息）。
   文案走两个宿主各自的本地化，键名在核心定一份。

⚠️ 「连续两次粘贴」在各家 CLI 里的表现没实测过，是真机验收的一格（§7）。若某家把第二次
吞掉或并进路径导致图片不识别，退路是两次之间等到第一次被回显之后再发；不许改成一次
粘贴里塞两样。

## 5. 文件放哪、怎么清

- 目录：`$XDG_STATE_HOME/polter/shots/`（Windows 回退 `%LOCALAPPDATA%\polter\shots\`），
  与项目、会话等既有状态目录同一规则。配置项 `screenshot-directory` 可改（应对 Gemini CLI
  对工作区外路径的限制）。
- 文件名：`YYYYMMDD-HHMMSS-mmm.png`，本地时间，纯 ASCII、小写扩展名、无空格。
- 清理：宿主启动时删掉该目录里**修改时间早于 7 天**、且文件名匹配上面模式的 `.png` 与
  同名 `.json`。只认这个模式——用户把目录指到别处时，不许删掉不是我们写的文件。
- 文件权限：POSIX 下 `0600`，目录 `0700`。

## 6. 权限

| | 第 1 步 | 第 2 步 |
|---|---|---|
| mac | 无 | 「屏幕录制」。首次触发时走系统授权；没授权时给一句话说明并指到系统设置，不许截出一张只有桌面背景的图当成功。需要在工程里补 usage description |
| Windows | 无 | 无 |

第 2 步都不要「辅助功能」权限。

## 7. 验收（真机，两平台各一轮）

1. 系统截图到剪贴板 → 在 Claude Code / Codex 里按粘贴键 → 出现图片附件。
2. `clipboard-paste-image = false` 时行为与改动前一致。
3. Polter 在后台、别的应用在前台时按热键能截；`Esc` 后剪贴板没变、目录里没多文件。
4. 悬停高亮跟着窗口走；单击选窗口得到的图边界与窗口一致（报像素读数）。
5. 标注五种工具各用一次 → 合成图里都有；`.json` 里条目与位置对得上。
6. 完成后粘进另一个应用得到合成图。
7. 从 Polter 前台触发 → 图片附件 + 标注文本都到了 CLI（两次粘贴那一格）。
8. 两个显示器、缩放不同时各截一张，尺寸是物理像素。
9. 目录里放一个 8 天前的截图和一个 8 天前的无关文件，重启后前者没了、后者还在。
11. 修饰键 + 双击：在别的应用前台时能触发，出来时光标下的窗口已选中；只按修饰键单击、
    或多按一个修饰键双击都不触发；mac 全程没弹任何授权。
12. Windows：`ctrl+shift+0` 在装了中文输入法的机器上按得出来（否则换默认值）。
10. Windows：Claude Code 原生 Windows 版能否识别 `C:\…` 路径粘贴（未确认，读数要报）。

## 8. 已知不做 / 已知限制

- SSH 到远端时不通：文件和剪贴板都在本地。
- aider 不识别粘贴的路径（它只有 `/paste` 和 `/add`）。
- 选区不识别窗口内的控件；不取浏览器 URL、不做文字识别、不读无障碍树。
