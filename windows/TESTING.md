# Polter on Windows — 内部测试说明

## 一、怎么开始

你拿到的是一个文件夹，里面**六样**东西。**双击 `polter-host.exe` 就行，不用设任何环境变量。**

```
polter-<构建号>\
    polter-host.exe                    <- 双击这个
    ghostty-internal.dll               ┐ 这两个必须和 exe 来自同一次构建
    ghostty-vt.dll                     ┘
    share\
        terminfo\ghostty.terminfo      <- 核心的兜底哨兵（本包里不走这条路，仍要带）
        ghostty\                       <- 插件、主题、shell 集成
        locale\                        <- 界面翻译，32 个 .mo；必须和 ghostty\ 并排
```

**`share\` 底下那三样是一组，不能挑着拷**，而它们各自是被**不同的东西**找到的 —— 这一段值得读，因为漏掉任何一样都不会有人报错：

| 这一样 | 谁在找它 | 怎么找 |
| --- | --- | --- |
| `share\ghostty\` | **主程序**，启动时 | 找 exe 同级的 `share\ghostty\poltergeist\`；找到才设 `POLTER_RESOURCES_DIR` |
| `share\locale\` | **核心**，加载翻译时 | 从上面那个目录**往上一级**再进 `locale\`。⚠️ **所以 `locale\` 必须和 `ghostty\` 并排**，挪走任何一个另一个就失效 |
| `share\terminfo\ghostty.terminfo` | 核心的**兜底**路径 | 只有在 `POLTER_RESOURCES_DIR` 没设或不被接受时才会用到。**双击本包里的主程序时它不参与**，但仍然要打进来：不打，兜底路径就没有了 |

**漏掉之后长什么样 —— 和「这些功能没做」在屏幕上一模一样：**

| 漏了哪一样 | 你会看到 |
| --- | --- |
| `share\ghostty\` | 插件、主题、shell 集成**和翻译一起**安静地不存在。程序照常起、终端照常能用；看起来像十几个功能没做，其实是一个目录没拷 |
| `share\locale\` | ⚠️ **设置页、菜单、命令面板仍然是英文，其它一切正常。** 这一条最难认：**「翻译还没做」和「翻译没打包」在屏幕上逐字相同** |
| `share\terminfo\ghostty.terminfo` | **本包里什么都看不出来**（见上表最后一行）。它的缺席不产生任何一行日志 |

### 出包之后先跑一次，看这两行在不在

**这一步是给打包的人的，也是给你的**：起一次主程序，在 `polter-host-<进程号>.log` 里找这两行。**它们比清单可靠 —— 清单是人对着打的，这两行是程序自己说的。**

```
[res] POLTER_RESOURCES_DIR = "…\share\ghostty" (beside the executable)
info(i18n): loaded catalog locale=zh_CN entries=… path=…\share\locale\zh_CN\LC_MESSAGES\….mo
```

| 哪一行不在 | 说明什么 | 怎么办 |
| --- | --- | --- |
| 第一行不在（日志里改成 `[res] no resources directory found next to the executable`） | `share\ghostty\` 没打进来，或者不在 exe 同级 | **别测。** 插件、主题、shell 集成、翻译这一轮的读数**全部作废** |
| 第二行不在（往下找 `info(i18n): no catalog path=… err=…`） | `share\locale\` 没打进来，或者没和 `share\ghostty\` 并排 | ⚠️ **别报「翻译坏了」。** 这一轮所有关于界面语言的读数**作废，不是缺陷** |

⚠️ **这两行看不见的事**：`share\terminfo\` 在不在，它们**一行都答不了** —— 双击本包时没有任何代码读它。**要核它只能直接看文件在不在**（下面第一行）。

### 屏幕之前，先核这三样

在包的目录里跑（PowerShell）：

| 核什么 | 命令 | 应当是 |
| --- | --- | --- |
| 兜底哨兵在不在 | `Test-Path share\terminfo\ghostty.terminfo` | `True` |
| 翻译打了几份 | `(Get-ChildItem share\locale -Recurse -Filter *.mo).Count` | **32** |
| 中文那份是不是这棵树的 | `(Get-ChildItem share\locale\zh_CN\LC_MESSAGES\*.mo).Length` | **30959** |

**任何一行不对，就是包没打全，别往下测** —— 之后看到的每一个「没做」都可能只是这一件事。**三样都对、上面两行日志也都在，界面仍然是英文** —— 那才是产品的问题，请照第六节报回来。

> 那 32 和 30959 是从源码树量的：`po\` 下 32 份翻译各出一个 `.mo`，中文那份由 GNU gettext 0.21 的 `msgfmt` 编出来是 30,959 字节。**换一个大版本的 `msgfmt` 可能给出别的字节数**，所以对不上先问打包的人用的是哪个版本，再当成缺陷。

插件目录不用你准备：程序自己在 `%LOCALAPPDATA%\polter\plugins` 下建。

## 二、起来之后，先看三行日志

日志就在 `polter-host.exe` 旁边，文件名 `polter-host-<进程号>.log`（一次运行一个文件，挑时间最近的那个）。想放别处可以设环境变量 `POLTER_HOST_LOG`，但测试用不着。

**这三行值得先看一眼，每一行都能省你半小时：**

```
[build] host and ghostty-internal.dll are a pair (both from a1b2c3d4e)
[build] tester's notes: C:\app\TESTING.md
[res]   POLTER_RESOURCES_DIR = "C:\...\share\ghostty"
```

| 这一行如果说 | 意思 | 怎么办 |
| --- | --- | --- |
| `MISMATCH` | 主程序和它的核心来自不同的构建 | **先别测。** 之后看到的任何异常都可能只是这件事，把那行发回来 |
| `tester's notes: NOT here` | 这份构建没带上说明 | 找打包的人要一份，别照着一份不知道从哪来的旧的测 |
| `no resources directory found next to the executable` | `share\ghostty\` 没带上，或者不在 exe 同级 | 去要完整的那份，否则上面说的那一堆「安静地不存在」正在发生。先按第一节那两行日志和三行命令核一遍 |

第一行里那串字符就是**你手上这一版**。第六节报问题的时候还要用它一次。

> **这份说明和主程序说的不一致时，信主程序。** 这份文件是被拷到构建旁边的，没有任何机制保证它和主程序同龄 —— 上面那行才是判断你手上是什么的唯一依据。

## 三、这一版值得试什么

不是完整功能表，是**这一轮刚动过、最值得你去按一按**的地方。

- **分屏**：切开、用鼠标拖中间那条分隔条改大小。
- **标签**：新建、关闭、**用鼠标拖着换顺序**、在标签上点右键。
- **把文件从资源管理器拖进终端窗口** —— 应当在光标处插入它的路径（带空格的路径会自动加引号）。
- **设置页**：左边选插件，右边填它的参数；改完保存。
- **查找**：在终端里开查找条，输入要找的字，`F3` / `Shift+F3` 跳下一个和上一个。
- **命令面板**。
- **群聊**：`Agents ▸ 终端群聊`。**这一版第一次能打字了** —— 按 `Enter` 出现输入行，打完再按 `Enter` 发送，`Esc` 放弃。
- **中文输入**：在终端里、在设置页的输入框里、在群聊的输入行里各打几个字。

**几个键和 macOS 不一样，试的时候别按老习惯**：

| 键 | 做什么 |
| --- | --- |
| `Ctrl+Shift+X` | 关掉当前分屏（**不是** `Ctrl+Shift+W`，那个是关标签） |
| `Ctrl+Shift+K` | 清屏 |
| `Shift+Home` / `Shift+End` | 滚到最顶 / 最底 |
| `Shift+PageUp` / `PageDown` | 上下翻页 |
| `Ctrl+Shift+Home` / `Ctrl+Shift+End` | **把已有的选区**扩到最开头 / 最末尾 |
| `Alt+Shift+PageUp` / `PageDown` | **把已有的选区**上下扩一页 |
| `F3` / `Shift+F3` | 查找的下一个 / 上一个（只在查找条开着时属于我们） |

**最后三行那几个是「扩展选区」，不是滚动，而且它们需要先有一个选区。** 没选任何东西的时候按下去，**屏幕一动不动是对的** —— 那不是坏了。要试它：先用鼠标拖选一段（或者按住 `Shift` 敲几下方向键），再按 `Ctrl+Shift+Home`。

## 四、已知问题 —— 这些**不用**报

我们已经知道了，报上来只会占掉你和我们的时间。

### 输入法候选词窗口开着的时候，**所有**快捷键都不响应

打中文时，只要候选词那个小窗还浮着，`Ctrl+Shift+C`、`Ctrl+Shift+T`、`F3`……一个都不会有反应。把候选词选定或按 `Esc` 收掉之后就恢复正常。

**这是一个问题，不是十几个。** 请不要给每一个失灵的快捷键各报一条 —— 它们全部是同一个原因，我们已经在查了。

### 其余五条

- **群聊的输入行只能往后打字和退格**，不能把光标移到中间去改。打错了要一路退回去。
- **下拉框选项超过 30 个时，鼠标够不到第 31 个以后的**（列表没有滚动条）。**键盘可以** —— 用上下箭头或 `End`。今天没有插件声明这么多选项，你多半碰不到。
- **有些菜单项右边不显示快捷键，但那个键是能用的 —— 一共 30 条，其中 12 条是 Windows 特有的。**
  ⚠️ **这句话原来只说「有些」，而「有些」让人以为是零星几条、不值得追。** 实际是菜单里
  48 个动作中的 30 个。**最常撞到的是分屏那一批**：`goto_split`（在分屏间跳）和
  `resize_split`（改分屏大小）共十条，**菜单上一个提示都没有，键全是好的**。
  成因写在 `docs/windows/keys.md` §3.7。**不用报。**
- **设置页里下拉框的那圈边框是系统画的**，深色主题下它仍然偏亮。这一处我们管不到。
- **窗口全部关掉之后进程才退出**，中间可能有短暂的延迟。
- ⚠️ **「设置…」（`Ctrl+,`）弹出「你要如何打开这个 .polter 文件？」—— 在没有关联的机器上这是预期行为。**
  那一行打开的是**配置文件**（`config.polter`），不是设置页——**这是上游的安排**，
  macOS 上 `Cmd+,` 的 `Preferences…` 做的是同一件事。而 `.polter` 这个扩展名在裸机上
  没有任何程序认领，于是 Windows 按它一贯的做法问你用什么打开。
  **选一次记事本（勾上「始终」）就不会再问。** ⚠️ **不必为了测试去建立这个关联**——
  如果你已经建立了，请在报告里说一句，否则我们分不清你测的是哪种机器。
  **设置页在别处：智能体 → 插件…**
- ⚠️ **`Shift+Insert` 粘贴不了 —— 这一条要报，但请只报一次。** 我们已经知道：那个和弦
  被绑给了「粘贴选区」，而 Windows 没有选区剪贴板，宿主会拒绝（日志里是
  `[clip] read … refused: no selection clipboard on Windows`）。**`Ctrl+V` 是好的。**
  列在这里是因为它长得像「粘贴坏了」，而其实坏的只有这一个和弦。

### ⚠️ 密码提示符处**截不到图**，这是本包新加的，而且默认是开着的

安全输入打开时，Polter 会向 Windows 要 `WDA_EXCLUDEFROMCAPTURE`，
把**整个窗口**从屏幕捕获里摘出去。于是：

- **截图工具（Snipping Tool、`Win+Shift+S`、远程桌面、会议软件的共享）拍到的
  是一块黑色或空白**，而你自己的眼睛看得见画面。
- 安全输入一关（该窗口里最后一个终端离开安全输入），窗口自动恢复正常，
  截图又能拍到了。

**⚠️ 在 Windows 上安全输入只有一个入口：命令面板里的 `Toggle Secure Input`。**
它没有默认快捷键，也不在菜单里，**面板里显示的是英文标题**（这一条的标题在
Windows 上不翻译）。中文可以搜**「安全输入」「切换安全输入」「密码输入」**——
这三个词是这一版才加进同义词表的，更早的包里搜中文搜不到。

**⚠️ 而且它在日志里的名字和面板里的名字不一样**：面板里那条叫
`toggle_secure_input`，它发出的动作在日志里叫 `secure_input`。
**按 `secure_input` 去搜面板会搜不到**，反过来也一样。**`sudo` / `ssh` 那种密码提示不会自动触发它** ——
核心里做这件事的是一个轮询 termios 的定时器（`src/termio/Exec.zig`），
那个定时器在 Windows 上根本不启动（源码里写着 `TODO: support on windows`）。
所以：**看到密码提示而画面照样能截图，这是今天的正常行为，不用报。**

**这不是坏了，也不用报。** 但它会在一个地方咬人：**你正想截图记录一个 bug，
而那一刻你（或别人）把安全输入打开着**——你会以为截图工具坏了。

看不到画面的时候，按顺序想这三件事：

1. **日志里有没有那一行。** 搜 `[capture]`：开保护、撤保护、以及调用失败，
   三种情况各有一行，`w<编号>` 说的是哪个窗口。**日志诚实，画面不诚实。**
2. **UIA 仍然可用。** 这个开关只挡像素，**完全不影响辅助功能树** ——
   读屏软件、`uia-tree-dump.ps1`、任何走 UIA 的探针，在保护开着的时候
   照样读得到窗口里的全部内容。要留证据就用它，不要跟截图较劲。
3. **实在需要截图**，在配置文件里写
   `windows-secure-input-exclude-from-capture = false` 再重开。
   关掉之后日志会明说这个窗口**没有**被保护。

> 顺带一句，反过来也成立：**这个开关不是保密手段**。它挡的只有屏幕捕获，
> 挡不住读屏软件、挡不住 UIA、更挡不住站在你身后的人。

### 2026-09-04 这一批新修的，如果你手上是更早的包会撞到

下面这些**在本包里已经修好**。列出来是因为：**如果你手上的包早于本包的构建号，它们仍在**，
而其中两条会悄悄毁掉你正要发给我们的证据。

- ⚠️ **别用 `>>` 攒命令输出**（`polter +version >> out.txt` 这种）。在更早的包里，
  **每一次 `>>` 都会把那个文件先前的内容整个删掉**，只留最后一次。
  单次 `>` 和管道是正常的，所以这个毛病在一次性用法下完全看不出来——
  **它只在你「攒」的时候咬人，而攒输出的正是在收集证据的人。**
- ⚠️ **更早的包里，把日志路径钉住（设 `POLTER_HOST_LOG`）之后再让 AI CLI 起来，
  那份日志会被删掉重建。** 本包里 `+mcp` 这类子进程不再拥有那份日志，会写自己的
  `polter-host-<进程号>.log` 并在 stderr 上说一句它写去了哪儿。
- **命令失败时不再一声不吭**：更早的包里 `polter +mcp` 在 Polter 外面运行会退出、
  而 stdout / stderr / 日志全是空的；宿主还有八条失败路径**对日志说失败、对系统说成功**
  （退出码 0）。本包两样都修了，**所以脚本现在可以靠退出码判断成败**。

## 五、这些**没验过** —— 撞到请务必报

> **「没验过」不是「大概坏了」。** 它的意思是：**还没有人在真机上看过它工作或不工作**，所以你撞到的任何东西都是第一手的读数。**请不要绕开这几项，也不要因为「看起来像是我自己操作错了」就不报** —— 那种感觉本身就是要报的东西，它常常是我们把提示写错了，而不是你按错了。

- **屏幕阅读器的播报**：开着 Narrator 或 NVDA 时，新建/关闭/切换标签，读屏软件应当跟着念出变化。**测试机上收不到这类通知，所以这一整块从来没有被人听过。**
- **查找条属于谁**：分屏之后，在**左边**那个终端里打开查找、然后点一下**右边**那个让它拿到焦点、再关掉查找条。左边的高亮应当被清掉。**如果高亮留在屏幕上关不掉，请报。**
- **上面列的那几个新键位**：它们确实被系统交给我们了，**但「按下去真的做了那件事」这一半没验过**。按一个，看它有没有做它该做的。
- **群聊发出去的消息，别人收不收得到**：你在群里发一条之后，**请找另一个人（或另一个终端）确认他那边看得见**。你自己屏幕上出现了，只说明本地画出来了。
- **标签上那个关闭 × 的形状**：刚刚重画过，从没在真屏幕上看过。歪的、缺一角的、两笔不对称的，都请截图。

## 六、报问题的时候，请附这三样

1. **那行构建身份** —— 就是第二节那三行里的第一行（`[build] host and ghostty-internal.dll are a pair (both from …)`）。**没有它我们不知道你跑的是哪一版**，而不同版本的同一个症状可能是完全不同的原因。
2. **日志文件本身**。它就在 `polter-host.exe` 旁边，文件名是 `polter-host-<进程号>.log`（一次运行一个文件，所以挑时间最近的那个）。**整个文件发过来，不要只截最后几行** —— 出问题的那一步常常在更早的地方，甚至在你做那个操作之前。
3. **当时中文输入法是开着还是关着**。因为第四节那条头号问题，这一项不写，我们每次都得回头问你一遍。

有截图更好，尤其是画得不对的东西。
