# Polter on Windows — 内部测试说明

## 一、怎么开始

你拿到的是一个文件夹，里面四样东西。**双击 `polter-host.exe` 就行，不用设任何环境变量。**

```
polter-<构建号>\
    polter-host.exe        <- 双击这个
    ghostty-internal.dll   ┐ 这两个必须和 exe 来自同一次构建
    ghostty-vt.dll         ┘
    share\ghostty\         <- 目录，必须一起带着
```

**四样里只有最后一个不是文件，而它最容易被漏掉。** 只拷了三个 exe/dll 而没带 `share\ghostty` 的话，**程序照样起得来、终端照样能用** —— 但插件、主题、shell 集成会**全部安静地不存在**。那看起来像十几个功能没做，其实是一个目录没拷。

插件目录不用你准备：程序自己在 `%LOCALAPPDATA%\polter\plugins` 下建。

## 二、起来之后，先看三行日志

日志就在 `polter-host.exe` 旁边，文件名 `polter-host-<进程号>.log`（一次运行一个文件，挑时间最近的那个）。想放别处可以设环境变量 `POLTER_HOST_LOG`，但测试用不着。

**这三行值得先看一眼，每一行都能省你半小时：**

```
[build] host and ghostty-internal.dll are a pair (both from a1b2c3d4e)
[build] tester's notes: C:\app\TESTING.md
[res]   POLTER_RESOURCES_DIR = "C:\...\share\ghostty"
```

| 这一行如果说 | 意思 | 怎么办 |
| --- | --- | --- |
| `MISMATCH` | 主程序和它的核心来自不同的构建 | **先别测。** 之后看到的任何异常都可能只是这件事，把那行发回来 |
| `tester's notes: NOT here` | 这份构建没带上说明 | 找打包的人要一份，别照着一份不知道从哪来的旧的测 |
| `no resources directory found next to the executable` | `share\ghostty` 没带上 | 去要完整的那份，否则上面说的那一堆「安静地不存在」正在发生 |

第一行里那串字符就是**你手上这一版**。第六节报问题的时候还要用它一次。

> **这份说明和主程序说的不一致时，信主程序。** 这份文件是被拷到构建旁边的，没有任何机制保证它和主程序同龄 —— 上面那行才是判断你手上是什么的唯一依据。

## 三、这一版值得试什么

不是完整功能表，是**这一轮刚动过、最值得你去按一按**的地方。

- **分屏**：切开、用鼠标拖中间那条分隔条改大小。
- **标签**：新建、关闭、**用鼠标拖着换顺序**、在标签上点右键。
- **把文件从资源管理器拖进终端窗口** —— 应当在光标处插入它的路径（带空格的路径会自动加引号）。
- **设置页**：左边选插件，右边填它的参数；改完保存。
- **查找**：在终端里开查找条，输入要找的字，`F3` / `Shift+F3` 跳下一个和上一个。
- **命令面板**。
- **群聊**：`Agents ▸ 终端对话`。**这一版第一次能打字了** —— 按 `Enter` 出现输入行，打完再按 `Enter` 发送，`Esc` 放弃。
- **中文输入**：在终端里、在设置页的输入框里、在群聊的输入行里各打几个字。

**几个键和 macOS 不一样，试的时候别按老习惯**：

| 键 | 做什么 |
| --- | --- |
| `Ctrl+Shift+X` | 关掉当前分屏（**不是** `Ctrl+Shift+W`，那个是关标签） |
| `Ctrl+Shift+K` | 清屏 |
| `Shift+Home` / `Shift+End` | 滚到最顶 / 最底 |
| `Shift+PageUp` / `PageDown` | 上下翻页 |
| `Ctrl+Shift+Home` / `Ctrl+Shift+End` | **把已有的选区**扩到最开头 / 最末尾 |
| `Alt+Shift+PageUp` / `PageDown` | **把已有的选区**上下扩一页 |
| `F3` / `Shift+F3` | 查找的下一个 / 上一个（只在查找条开着时属于我们） |

**最后三行那几个是「扩展选区」，不是滚动，而且它们需要先有一个选区。** 没选任何东西的时候按下去，**屏幕一动不动是对的** —— 那不是坏了。要试它：先用鼠标拖选一段（或者按住 `Shift` 敲几下方向键），再按 `Ctrl+Shift+Home`。

## 四、已知问题 —— 这些**不用**报

我们已经知道了，报上来只会占掉你和我们的时间。

### 输入法候选词窗口开着的时候，**所有**快捷键都不响应

打中文时，只要候选词那个小窗还浮着，`Ctrl+Shift+C`、`Ctrl+Shift+T`、`F3`……一个都不会有反应。把候选词选定或按 `Esc` 收掉之后就恢复正常。

**这是一个问题，不是十几个。** 请不要给每一个失灵的快捷键各报一条 —— 它们全部是同一个原因，我们已经在查了。

### 其余五条

- **群聊的输入行只能往后打字和退格**，不能把光标移到中间去改。打错了要一路退回去。
- **下拉框选项超过 30 个时，鼠标够不到第 31 个以后的**（列表没有滚动条）。**键盘可以** —— 用上下箭头或 `End`。今天没有插件声明这么多选项，你多半碰不到。
- **有些菜单项右边不显示快捷键，但那个键是能用的。** macOS 上同样不显示，这不是 Windows 版特有的。
- **设置页里下拉框的那圈边框是系统画的**，深色主题下它仍然偏亮。这一处我们管不到。
- **窗口全部关掉之后进程才退出**，中间可能有短暂的延迟。

## 五、这些**没验过** —— 撞到请务必报

> **「没验过」不是「大概坏了」。** 它的意思是：**还没有人在真机上看过它工作或不工作**，所以你撞到的任何东西都是第一手的读数。**请不要绕开这几项，也不要因为「看起来像是我自己操作错了」就不报** —— 那种感觉本身就是要报的东西，它常常是我们把提示写错了，而不是你按错了。

- **屏幕阅读器的播报**：开着 Narrator 或 NVDA 时，新建/关闭/切换标签，读屏软件应当跟着念出变化。**测试机上收不到这类通知，所以这一整块从来没有被人听过。**
- **查找条属于谁**：分屏之后，在**左边**那个终端里打开查找、然后点一下**右边**那个让它拿到焦点、再关掉查找条。左边的高亮应当被清掉。**如果高亮留在屏幕上关不掉，请报。**
- **上面列的那几个新键位**：它们确实被系统交给我们了，**但「按下去真的做了那件事」这一半没验过**。按一个，看它有没有做它该做的。
- **群聊发出去的消息，别人收不收得到**：你在群里发一条之后，**请找另一个人（或另一个终端）确认他那边看得见**。你自己屏幕上出现了，只说明本地画出来了。
- **标签上那个关闭 × 的形状**：刚刚重画过，从没在真屏幕上看过。歪的、缺一角的、两笔不对称的，都请截图。

## 六、报问题的时候，请附这三样

1. **那行构建身份** —— 就是第二节那三行里的第一行（`[build] host and ghostty-internal.dll are a pair (both from …)`）。**没有它我们不知道你跑的是哪一版**，而不同版本的同一个症状可能是完全不同的原因。
2. **日志文件本身**。它就在 `polter-host.exe` 旁边，文件名是 `polter-host-<进程号>.log`（一次运行一个文件，所以挑时间最近的那个）。**整个文件发过来，不要只截最后几行** —— 出问题的那一步常常在更早的地方，甚至在你做那个操作之前。
3. **当时中文输入法是开着还是关着**。因为第四节那条头号问题，这一项不写，我们每次都得回头问你一遍。
