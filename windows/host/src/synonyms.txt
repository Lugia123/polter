# Words a person is likely to type, and the command the core actually publishes.
#
# **This is an index, not a naming.** Nothing here renames anything: each line
# says "if they type the left, they mean the right". A line whose right-hand
# side no longer exists therefore degrades to today's behaviour -- the search
# simply does not match -- rather than pointing at the wrong command. The
# startup log reports how many lines have no matching command, so a stale one
# is visible rather than silent.
#
# Every line came from comparing macOS's MainMenu.xib against the core's own
# command list; 20 of that menu's 69 commands are the same action under a
# different word. Adding a line from memory is exactly what the Zig test
# `test "palette synonyms name real commands"` exists to catch.
#
# Format: <what they type> = <the core's title>

# ---------------------------------------------------------------- menu labels
#
# **The other half of the same problem.** The lines above are English words a
# person might type instead of the core's own. These are the words this host
# puts on its own menus -- in Chinese -- and without them somebody who reads
# «关闭窗口» off the menu and types those four characters into the palette gets
# nothing, while `close` lists five commands they cannot name. The menu is the
# most likely place a person learned the word, so it is the least likely word
# to be missing here.
#
# **Generated from the menu table, not typed from memory.** Every line below is
# one row of `menu.rs`'s table paired with the title the core publishes for
# that row's action, and `test "menu labels reach the palette"` in
# `src/input/command.zig` fails if a row loses its line -- or if a line names a
# title the core does not publish.
#
# Six menu rows have no line and cannot: `toggle_command_palette`,
# `toggle_quick_terminal` and the four `resize_split:<dir>,10` rows name
# actions **the core publishes no palette command for**, so there is nothing
# for a search to find. That is a fact about the core's list, not an
# exemption written here, and the test computes it rather than being told.
